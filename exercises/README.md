# Exercise files

One folder per exercise that needs more than the bare starter. A folder holds
only the files the student copies into a fresh app created from
[vite-ts-starter](https://github.com/Teaching-HTL-Leonding/vite-ts-starter) (or
`vite-ts-starter-tests` from the testing part on): an `index.html`, a
`src/styles.css`, a base class, a half-written test file. Never a complete
project, never `package.json` or `node_modules`.

The chapter names the folder and says which file goes where. Sample solutions
do not live here; they stay with the teacher.
